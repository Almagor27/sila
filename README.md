 Система идентификации личности - это авторская система, помогающая определить некоторые аспекты вашей личности, используя лишь дату своего рождения. После введения даты рождения (свою, или кого - либо другого), на экране появится график. На оси Х годы жизни. на оси Y цифры, каждая из которых соответствует одному из небесных тел солнечной системы. Описание качеств, которые соответствуют небесному телу приведено  открывающейся вкладке. Интуитивно понятный интерфейс не даст заблудиться. С помощью этой системы вы можете путешествовать как в будущее, так и в прошлое. График цикличен. Для кого то этот цикл составляет пять лет, для кого-то шесть. Каждые пять, или шесть лет вы попадаете на одну и ту же цифру а значит. можете сопоставить происходящее с вами в цикличности. Если у кого то из вас появятся вопросы, в самом низу есть кнопка связи с автором. Приятного исследования!
